# Security policy

Report vulnerabilities through GitHub Security Advisories. Never place live
capabilities, pairing URLs, user filenames, or file contents in an issue.

The in-memory store is a reference implementation, not a durability claim.
Before accepting untrusted internet traffic, configure per-application rate
limits, a malware scanning/quarantine stage, encrypted object storage, an
expiry sweeper, audit events without secrets, and an edge/body-size limit.
